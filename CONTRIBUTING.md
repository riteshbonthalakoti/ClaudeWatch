# Contributing to ClaudeWatch

First off, thank you for considering contributing to ClaudeWatch! It's people like you that make ClaudeWatch such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make one! It's generally best if you get confirmation of your bug or approval for your feature request this way before starting to code.

## Fork & create a branch

If this is something you think you can fix, then fork ClaudeWatch and create a branch with a descriptive name.

## Code Conventions
- We follow standard `flutter analyze` rules.
- Write tests for new features.
- Keep commits focused and atomic.

## Pull Request Process
1. Ensure your code passes all CI checks.
2. Update the README.md with details of changes if required.
3. Your PR will be reviewed by maintainers.
