# Security Policy

## Supported Versions

Please refer to the `SUPPORTED_VERSIONS.md` file for details on which versions are currently receiving security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within ClaudeWatch, please DO NOT open a public issue. Instead, send an email to the maintainers or use the private vulnerability reporting tool provided by GitHub.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability, you may be eligible for a bounty (if applicable in the future) and acknowledgment in our security advisories.
